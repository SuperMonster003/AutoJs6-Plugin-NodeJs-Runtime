# AutoJs6 Node.js Runtime

Этот плагин предоставляет нативную среду выполнения Node.js 24.21.0 для AutoJs6.

Установите и включите плагин в центре плагинов AutoJs6, затем запустите скрипт так:

```js
"nodejs";

console.log(process.version);
```

Слот среды выполнения: `node24_5`. Поддерживаются сборки `arm64-v8a`, `armeabi-v7a` и `x86_64`, а также APK `universal`.

Примеры проектов находятся в `sample/nodejs`.

В настройках плагина доступны 1-8 параллельных запусков (по умолчанию 2) и размер очереди (по умолчанию без ограничений); остальные скрипты ожидают в порядке FIFO, изменения сохраняют принятые задачи, а idleExitMs освобождает простаивающие процессы
