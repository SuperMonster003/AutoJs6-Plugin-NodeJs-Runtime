# AutoJs6 Node.js Runtime

このプラグインは AutoJs6 に Node.js 24.5.0 ネイティブランタイムを提供します.

AutoJs6 プラグインセンターでインストールして有効化し, 次の指示でスクリプトを開始します:

```js
"nodejs";

console.log(process.version);
```

ランタイムスロットは `node24_5` です. `arm64-v8a`, `armeabi-v7a`, `x86_64` ビルドと `universal` APK をサポートします.

サンプルプロジェクトは `sample/nodejs` にあります.
