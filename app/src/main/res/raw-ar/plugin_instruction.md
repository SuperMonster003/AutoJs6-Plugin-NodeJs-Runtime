# AutoJs6 Node.js Runtime

يوفر هذا الملحق بيئة تشغيل Node.js 24.5.0 الاصلية ل AutoJs6.

ثبت الملحق وفعله في مركز ملحقات AutoJs6, ثم ابدأ سكربتا باستخدام:

```js
"nodejs";

console.log(process.version);
```

فتحة بيئة التشغيل هي `node24_5`. يدعم builds `arm64-v8a`, `armeabi-v7a`, و `x86_64`, اضافة الى APK `universal`.

توجد مشاريع الامثلة في `sample/nodejs`.
