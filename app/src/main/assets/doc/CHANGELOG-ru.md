# v1.3.0

###### Не выпущено

* `Новое` Подписки моста Node.js передают события датчиков, WebSocket, интерфейса, оверлеев и ввода через существующие обратные вызовы с on/once/off, ограниченными очередями и совместимостью с drainEvents
* `Новое` Необязательный idleExitMs завершает простаивающий процесс Node.js с повторным подключением следующего скрипта; диагностика idleForMs, по умолчанию процесс остаётся активным
* `Новое` Глобальные fetch, Request, Response, Headers, FormData и WebSocket используют нативные Web API Node; autojs6:fetch и autojs6:websocket сохраняют сетевой стек хоста
* `Новое` Добавлен нативный node:sqlite с проверкой путей, CRUD, транзакциями и резервным копированием; доступны нативные отчёты node:test и рабочий пример, офлайн-корпус npm дополнен zod, cheerio, date-fns, mqtt и ws
* `Новое` Ввод из консоли через process.stdin / readline и JSON-сообщения для каждого запуска через autojs6:host; транзакция postMessage v3 совместима с прежними хостами
* `Новое` Сеансы захвата экрана Node.js используют разрешение Android и существующую службу переднего плана, поддерживают дескрипторы изображений, сохранение PNG/JPEG/WebP и очистку при остановке или завершении скрипта
* `Новое` Дескрипторы изображений Node.js поддерживают обрезку, масштабирование, оттенки серого, пороговую обработку и поиск шаблонов или цветов через обработчик хоста, с независимыми результатами и очисткой при завершении
* `Исправление` Исправлено накопление запросов и ответов моста в постоянно работающих скриптах: завершённые запросы удаляются, а диагностика хранит только последние 32 ответа с ограничением размера
* `Исправление` Исправлена преждевременная фиксация успеха, терявшая нативные асинхронные ошибки и поздние коды выхода; результат формируется при окончательном выходе цикла Node
* `Улучшение` Снижена задержка моста благодаря транспорту JNI/Binder по умолчанию и ответам через цикл событий Node; сохранены файловый транспорт и ограничения ожидающих вызовов
* `Улучшение` Восстановлены нативные экспорты Node.js для stream, crypto, timers, util, node:test и других модулей с сохранением границ файловой системы и каталогов хоста
* `Улучшение` Число нативных worker по умолчанию соответствует параллелизму CPU (до восьми); они наследуют настройки сети и файлов и поддерживают лимиты ресурсов запроса. Тайм-аут задач пула по умолчанию отключён, примеры CPU и WASM выполняются в реальных worker
* `Улучшение` Нативный WASI остаётся отключённым для сохранения границ файловой системы; удалены два отключённых примера WASI, обычный WebAssembly и WASM workers остаются доступны
